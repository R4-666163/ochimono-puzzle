# ビー玉トリオ（ochimono-puzzle）

三角の3つ組ビー玉を蜂の巣状に積んで、CPUと対戦する落ちものパズルゲーム。

## 遊び方

公開中：https://ochimono-puzzle.rsj58g310.workers.dev （Cloudflare。GitHub の main に push すると自動で更新される）

`site/index.html` をブラウザで開くだけで遊べます（スマホ対応）。

- 支えのない玉は、すき間へ転がり落ちる
- 同じ色を6つ以上つなげると消える。じゃま玉が降ってきて同じ色が6つ以上つながったときも、着地した時点で消える
- 次の「わざ」（同じ色6つの決まった形。まわりに同じ色がくっついていてもよい）で消すと、その色の玉がフィールドからぜんぶ消え、相手にじゃま玉（白いふち付き）が降る。それ以外の消し方では降らない。1つのかたまりに形がいくつ入っていても、いちばん強いわざ1つとして数える
  - ピラミッド（上から1・2・3個）… 24個
  - 逆ピラミッド（上から3・2・1個）… 24個
  - ストレート（横、またはななめに6つ）… 19個
  - ヘキサゴン（6つでぐるっと輪をつくる。真ん中は空でも、別の色でも、同じ色でもよい）… 36個
- 降ってきたじゃま玉でわざの形ができたときも、その場で消えて相手にじゃま玉を送れる
- じゃま玉は、作ったわざと同じ形の連なりで、まとめて降ってくる。ピラミッド・ヘキサゴンは、1つの型の中で同じ色がとなり合わない。ストレート（横・ななめ）は、9個の段の上に半個ずらした8個の段（残り2個はその上）で、色は黄→紫→赤→青→緑のくり返し（上の玉は左下の玉と同じ色のペア）
- 連鎖の中でわざを重ねると、そのわざのぶんだけじゃま玉が増える（ふつうの消しや連鎖だけでは増えない）
- 相殺（届く前に打ち消す仕組み）はない
- ルールは「6ボールパズル」（マリオパーティ9／世界のアソビ大全51）に寄せている
- じゃま玉にも色があり、同じ色の玉とつながって消せる（決まった形にも使える）
- じゃま玉は、隣で玉が消えたときも一緒に消える
- 上の×印がふさがったら負け

## オンライン対戦（1対1）

公開ページ（Cloudflare）なら誰でも、ログインなしで遊べます。claude.ai のアーティファクトで開いたときも遊べます（`site/index.html` を直接開いたときは CPU 対戦のみ）。公開ページの人と claude.ai の人は、部屋のしくみが別なので対戦できません。

1. タイトル画面の「オンライン」を押す
2. 1人が「部屋を立てる」→ 6桁のコードが出る
3. もう1人が「部屋に入る」→ そのコードを入力
4. 「ゲームスタート!」が出て、対戦が始まる

- それぞれ自分の画面で自分の盤面を動かし、盤面とわざ（じゃま玉）をやりとりする。公開ページでは `src/index.js`（Cloudflare の Durable Object、部屋ごとに1つ）が WebSocket で中継し、claude.ai では room 機能を使う
- 対戦が終わったら「もう一回」か「やめる」を選ぶ。2人とも「もう一回」ならそのまま次の対戦、どちらかが「やめる」と2人ともホームにもどる
- 対戦中に相手が部屋を出たら勝ち。オンライン中は一時停止なし
- claude.ai で遊ぶ場合は、相手もそのアーティファクトを開ける（共有で招待された）claude.ai のアカウントでログインしている必要がある

## 操作

- ボタン：◀ ▶ 移動 ／ ⟳ 回転 ／ ▼ はやく ／ ⤓ 一気に落とす
- フィールド：タップで回転、左右になぞって移動、下にはらって落とす
- キーボード：← → 移動、↑ / Z / X 回転、↓ はやく、スペース 落とす、P / Esc 一時停止
