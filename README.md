# ビー玉トリオ（ochimono-puzzle）

三角の3つ組ビー玉を蜂の巣状に積んで、CPUと対戦する落ちものパズルゲーム。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（スマホ対応）。

- 支えのない玉は、すき間へ転がり落ちる
- 同じ色を6つ以上つなげると消える
- 次の「わざ」（同じ色ちょうど6つの決まった形）で消すと、その色の玉がフィールドからぜんぶ消え、相手にじゃま玉（白いふち付き）が降る。それ以外の消し方では降らない
  - ピラミッド（上から1・2・3個）… 24個
  - 逆ピラミッド（上から3・2・1個）… 24個
  - ストレート（横、またはななめに6つ）… 19個
  - ヘキサゴン（別の色の玉1つを、6つでぐるっと囲む）… 36個
- じゃま玉は、作ったわざと同じ形の連なりで、2個ずつ同じ色になって、まとめて降ってくる
- 連鎖の中でわざを重ねると、そのわざのぶんだけじゃま玉が増える（ふつうの消しや連鎖だけでは増えない）
- 相殺（届く前に打ち消す仕組み）はない
- ルールは「6ボールパズル」（マリオパーティ9／世界のアソビ大全51）に寄せている
- じゃま玉にも色があり、同じ色の玉とつながって消せる（決まった形にも使える。ヘキサゴンの真ん中にもなれる）
- じゃま玉は、隣で玉が消えたときも一緒に消える
- 上の×印がふさがったら負け

## 操作

- ボタン：◀ ▶ 移動 ／ ⟳ 回転 ／ ▼ はやく ／ ⤓ 一気に落とす
- フィールド：タップで回転、左右になぞって移動、下にはらって落とす
- キーボード：← → 移動、↑ / Z / X 回転、↓ はやく、スペース 落とす、P / Esc 一時停止
