# ビー玉トリオ（ochimono-puzzle）

三角の3つ組ビー玉を蜂の巣状に積んで、CPUと対戦する落ちものパズルゲーム。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（スマホ対応）。

- 支えのない玉は、すき間へ転がり落ちる
- 同じ色を6つ以上つなげると消える
- そのとき、消える玉と線でつながった組の玉も、色に関係なく一緒に消える
- 次の「決まった形」（同じ色ちょうど6つ）で消したときだけ、相手にじゃま玉（白いふち付き）が降る。それ以外の消し方では降らない
  - 三角形（上から1・2・3個）
  - 逆三角形（上から3・2・1個）
  - 一直線（横、またはななめに6つ）
  - ヘキサゴン（別の色の玉1つを、6つでぐるっと囲む）
- じゃま玉にも色があり、同じ色の玉とつながって消せる（決まった形にも使える。ヘキサゴンの真ん中にもなれる）
- じゃま玉は、隣で玉が消えたときも一緒に消える
- 上の×印がふさがったら負け

## 操作

- ボタン：◀ ▶ 移動 ／ ⟳ 回転 ／ ▼ はやく ／ ⤓ 一気に落とす
- フィールド：タップで回転、左右になぞって移動、下にはらって落とす
- キーボード：← → 移動、↑ / Z / X 回転、↓ はやく、スペース 落とす、P / Esc 一時停止
